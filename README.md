# FairSHAP Assignment 4

I evaluate [FairSHAP](https://proceedings.mlr.press/v300/zhu26b.html) on German Credit, COMPAS and Adult, following [the authors’ code](https://github.com/lin1zhu0216/FairSHAP).

1. [Download ZIP](https://github.com/Achiee7/DW-Assignment-4-FairSHAP/archive/refs/heads/main.zip) and extract it.
2. Open `Assignment 4 FairSHAP.ipynb` in Jupyter or VS Code with Jupyter support.
3. Select **Python 3.12** and **Run All**.

The first cell installs packages automatically. Internet is needed for the first setup. Datasets and completed results are included.
